# Architecture

This repository documents an operating model rather than a software product.

The architecture has four layers:

1. **Intent** — product goals and current work.
2. **Context** — architecture, product laws, and current state.
3. **Execution** — bounded tasks performed on branches.
4. **Evidence** — tests, review, CI, and production/provider verification.

The key design constraint is that no single document should try to own all four layers.
